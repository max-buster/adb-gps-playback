# Example GTFS feeds

Feeds the apps can download on demand. This folder sits outside `android/` and
`web/`, so nothing here is packed into the APK or the web build. The Android
app fetches [`index.json`](index.json) from GitHub
(`raw.githubusercontent.com/max-buster/adb-gps-playback/main/samples/index.json`)
and lists it under **Load → Try an example / Examples**. Downloads go to the
app's private storage and stay there until the user deletes them.

## What's here

| Feed | What it exercises |
| --- | --- |
| `feeds/demo-manhattan.zip` | Two routes (Fifth Avenue, 42nd Street), both directions, with `shapes.txt`, route colors, stops and stop times |
| `feeds/demo-manhattan-no-shapes.zip` | The same routes without `shapes.txt`, so the stop-based fallback line is used |

Both are synthetic: a made-up agency and timetable laid over Manhattan's
street grid, released as CC0. They're generated by `build.py --demo`.

## `index.json`

```json
{
  "version": 1,
  "feeds": [
    {
      "id": "demo-manhattan",
      "name": "Demo: Manhattan (with shapes)",
      "description": "Shown under the name.",
      "region": "New York, US",
      "license": "CC0 (synthetic data)",
      "url": "feeds/demo-manhattan.zip",
      "sizeBytes": 6665,
      "sha256": "6c92…"
    }
  ]
}
```

- `id`: letters, digits, `.`, `_`, `-` (max 64). It's the file name on the
  device, so changing it means a fresh download.
- `url`: relative to `index.json`, or an absolute `https://` URL.
- `sizeBytes`, `sha256`: optional. When `sha256` is present the app rejects a
  download that doesn't match it. `build.py` fills both in for local files.
- Unknown fields are ignored. Bump `version` only for changes old app builds
  can't read; they'll then ask the user to update.

## Adding a feed

1. **Small (under ~5 MB):** drop the zip in `feeds/`, add an entry with a
   relative `url`, then run `python3 samples/build.py` to fill in size and
   checksum.
2. **Large:** don't commit it. Attach it to a GitHub Release (for example a
   `samples` release) and use the asset's download URL
   (`https://github.com/max-buster/adb-gps-playback/releases/download/samples/<file>.zip`).
   Release assets can be up to 2 GB and don't bloat clones. Add `sha256` only
   if you'll never replace the asset in place.
3. **An agency's public feed:** point `url` at the agency's own download link
   and leave `sha256` out, since those files change. Check the license allows
   redistribution before committing a copy instead.

Avoid Git LFS for these: `raw.githubusercontent.com` serves the LFS pointer
file, not the zip, and LFS downloads count against a bandwidth quota.

`android/core`'s `SampleIndexTest` checks that every local entry's size and
checksum match the file and that the zip parses, so run `./gradlew :core:test`
(or `build.py`) after changing anything here.
